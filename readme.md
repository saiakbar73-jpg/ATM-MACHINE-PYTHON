ATM Machine Project 🏧

About the Project

This is a simple ATM Machine application developed using Python. It allows users to perform basic ATM operations through a menu-driven program.

Features

* PIN verification
* Check account balance
* Deposit money
* Withdraw money
* Exit the ATM

Technologies Used

* Python 3

Default Login Details

* ATM PIN: 1234
* Initial Balance: ₹5000

How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

python ATM_MACHINE.py

5. Enter the ATM PIN when prompted.

Disclaimer

This is a beginner-level educational project. It does not connect to a real bank or handle real money.
